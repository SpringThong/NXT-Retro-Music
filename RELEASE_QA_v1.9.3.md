# v1.9.3 unified three-ROM source QA

This source tree is shared by Stock, NextUI and NX Redux for TrimUI Brick Pro. All three frontends were freshly compiled through `python3 tools/build-release.py --rom all --jobs 4`, with separate ROM defines, objects/settings libraries, installers and OTA kits. No public OTA feed was changed in this source-consolidation task.

- All three current BUILD_INPUTS fingerprints and ELF SHA-256 values match the bundled source. Real ARM64 ELF --build-info / --help load with QEMU and the pinned firmware SDK: pass with correct ROM and v1.9.3.
- Input preflight works for --rom all and each individual ROM; Makefile targets select explicit ROMs. SDK/compiler are downloaded automatically with pinned SHA-256 on the first build, not bundled in the source ZIP.
- Compared to the delivered v1.9.3 Stock/NextUI common source, all 821 frontend input files and 667 UI resources are byte-identical. Stock/NextUI release ELF bytes are also identical; NX Redux is rebuilt against this same current common source. Changes in this task are build routing, source metadata, documentation and verification.
- Final installers and OTA kits for all three ROMs pass CRC, executable permissions, version/config/state, correct official feed and app path, resource/backend identity, private-data exclusion and exact installer/manifest SHA/size checks. Only NX includes its settings adapter and Tools integration.
- Actual final installers through production OTA worker/installer under ASan/UBSan: pass for all three ROMs. Stock/NextUI fixtures start at v1.9.1, NX Redux at v1.9.2. Drive confirmation, size/SHA/ROM/HTML rejection, stage/install/backup, ready state and cancel/reaping checked. Credentials, profile, resume, wallpaper, translation cache, library DB and DAC name bytes retained.

Preserved existing functional evidence: shared incremental engine ASan/UBSan and ARM64 firmware SQLite; legacy eight-column migration/favorites, 2,048-track warm zero probes/writes/commits, edits/deletes, bounded batches/rollback/cancellation/missing-root safety. Production scheduler/view fixtures cover cached-first, no repeated entry scans, stable idle queries/folders, revision refresh, hidden/upload-busy condition-variable pause and debounce. Production Wi-Fi fixture covers completed notifications, partial/cancel/auth/UTF-8/collision safety. DSD fixtures cover 576 independent byte goldens, eight Native/DoP transports, actual worker/policy behavior, real-device error preservation, explicit Native-to-DoP, USB identity labels and diagnostics. These functional sources are unchanged and hash-verified; fixtures were not rerun only to consolidate the source.

Read BUILD_v1.9.3.md for Linux/WSL requirements, per-ROM/all-ROM commands, outputs, OTA publishing and future edits. Source packaging checks all three current fingerprints/reports and overlay hashes. Original libraries, backend sources, licenses and relink objects remain included.

No physical ROM boot/playback, DAC compatibility, underrun, heat, power or SD-wear measurement was performed here. Native DSD remains dependent on ROM/DAC support; DoP requires compatibility and explicit selection/confirmation. One source archive does not mean one install ZIP for every ROM.
