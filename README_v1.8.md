# NXT Retro Music v1.8 native source

Unified source for Stock and NextUI, based on the supplied v1.7.1 snapshot and approved v1.8 design. This is a Linux ARM64 player for TrimUI Brick Pro, not an Android APK or web renderer. See `docs/HUONG_DAN_NXT_Retro_Music_v1.8.md`.

Build: install Python 3.12+, run `python3 tools/sdk-assets.py` to fetch the pinned verified SDK, then `NXT_JOBS=2 python3 tools/build-stock.py` and `NXT_JOBS=2 python3 tools/build-nextui.py`. Static audio/text libraries and their source archives are bundled. `stock/frontend-sources.json` is the native frontend list. Build scripts correct executable modes for vendor ELF tools, and use separate ROM object directories. USB transfer helper is copied to tmp before app cleanup; no SD path remains as the launch working directory during unmount.

Recreate design chassis with Node and sharp: `npm install sharp` and `node tools/export-v18-scenes.cjs`. Avatar and IME preparation scripts use the pinned upstream revisions. Corresponding IME dictionary sources and licenses are bundled under `sources/ime/`; install Pillow, pypinyin 0.55.0, OpenCC and emoji 2.14.1 if rebuilding those resources. Locales are offline JSON. Build-time machine translation is optional and its model is not shipped in the app; primary UI labels have curated overrides. Native screenshots are in `qa/screens-v1.8/`; test reports are in `logs/`. See `RELEASE_QA_v1.8.md` for the completed checks and their limits. Tests use actual production modules with explicit controller/audio/firmware fixtures. Physical device temperature, real USB transport and authenticated playback are not claimed.

Package: run `tools/sync-overlay.py`, `tools/package-stock.py`, `tools/package-nextui.py`; OTA kits use `NXT_PACKAGE_ROM=stock|nextui python3 tools/package-ota-kit.py`. One source archive includes both ROM builds, tests, resources, third-party licenses and pinned full library source. User credentials/music/profile data and SDK caches are excluded.
